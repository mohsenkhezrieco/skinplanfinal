# SkinPlan v17.9 — report readability update

- Top report section is now a compact **Treatment roadmap** table.
- The roadmap contains only high-level information: phase/timing, main focus, main treatment and review checkpoint.
- Morning product repetition and weekday calendars were removed from the top summary.
- The 7-day Mon–Sun example is now shown **after the product-image routines inside each phase**, where it is easier to connect the schedule to the products.
- Later-phase weekly examples include an explicit reassessment warning: earlier treatments are not assumed to stop automatically.
- PNG and multi-page A4 PDF export are retained.
