# SkinPlan v16.3 — Complete AM/PM routine for every phase

The patient report now repeats the full routine whenever the programme changes.

For every treatment phase it shows:
- Morning — every day during that phase
- Each distinct evening treatment-night routine, with the selected product image
- Recovery-night routine
- The treatment frequency for that phase

When a later phase adds a second treatment, the previous treatment remains visible as a separate evening routine rather than disappearing from the report. Separate actives are never shown as being used on the same evening unless the engine explicitly allows it.

This intentionally makes the report longer, but a patient can read each phase independently without needing to refer back to the first page.
